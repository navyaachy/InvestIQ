# InvestIQ

### An Explainable Investment Decision-Support System

InvestIQ is a FinTech decision-support application designed to help investors analyse portfolio holdings and individual stocks using explainable, evidence-based analytics.

> **Important:** InvestIQ is a decision-support system, not financial advice or a guaranteed prediction system.

## Key Features
- Portfolio dashboard and allocation analysis
- P&L and return tracking
- Portfolio risk and diversification analysis
- Stock comparison and valuation context
- What-if scenario analysis
- Investment goal tracking
- Historical portfolio analysis
- News and event context
- Rule-based monitoring alerts
- Explainable investment analysis reports
- Data source and freshness transparency

## Technology Stack
Python | Pandas | NumPy | yFinance | Streamlit | Plotly | SQLite | Pytest

## Testing
The project includes automated tests for core analytics, module integrity, data freshness, and decision-support functionality.

## Data Sources
Market and financial data are retrieved from available external data providers, including Yahoo Finance. News context is retrieved through Google News RSS.

## Limitations
InvestIQ provides analytical decision support and does not guarantee future returns, predict prices with certainty, or provide personalised financial advice.
